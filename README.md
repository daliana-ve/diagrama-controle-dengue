# Monitoramento Epidemiológico da Dengue

Dashboard epidemiológico da Regional de Saúde de Colatina – ES.

## Abrangência

15 municípios da Regional de Saúde de Colatina.

## Fonte

e-SUS VS.

## Referência populacional

Estimativa populacional IBGE 2024.

## Critério temporal

As análises temporais são realizadas segundo a semana
epidemiológica de diagnóstico.

## Casos prováveis

São considerados casos prováveis todos os casos não descartados,
incluindo os casos ainda em investigação.

## Letalidade

Óbitos por dengue / casos de dengue com sinais de alarme
e dengue grave × 100.

## Sorotipos

São considerados somente registros com RT-PCR positivo
e sorotipo identificado.

## Proteção de dados

Os arquivos utilizados no dashboard contêm exclusivamente
dados agregados e não identificáveis.
